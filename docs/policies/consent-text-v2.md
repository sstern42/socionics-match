# Marketing-email consent wording, version v2

In use from 6 November 2026. Every `consent_events` row with
`consent_text_version = 'v2'` was recorded against the wording below. v2 adds
a second purpose, `purpose = 'socionics_signal'`: subscribing to Socionics
Signal, Spencer's email newsletter run from socionicsinsight.com through the
same MailerLite account. It does not change the Socion updates wording, which
stays in [`consent-text-v1.md`](consent-text-v1.md) and is still recorded as
`v1`.

Do not edit this file. Any change to this wording needs a new version string,
new source values for the capture points whose wording changed, and a new
`consent-text-v3.md` alongside this one. See `CLAUDE.md`.

Both capture points are one-click buttons that subscribe the member's account
email (shown in the text). Nothing is pre-selected; not clicking records
nothing. The click is recorded only after MailerLite has accepted the
subscriber (`supabase/functions/subscribe-signal`, `record_signal_opt_in()`).
Component: `src/components/feed/SignalSubscribe.jsx`; the closing sentence is
`SIGNAL_CONSENT_TEXT` in `src/lib/signal.js`.

## Opt-outs

A MailerLite unsubscribe, bounce or spam report (`mailerlite_unsubscribe`,
via `mailerlite-webhook` and `suppress_email()`) ends the Signal subscription
as well as Socion updates, because MailerLite unsubscribes are account-wide.
It writes a `socionics_signal` row with `consent_text_version = NULL`. The
unsubscribe link in Socion's own Resend emails (`email_unsubscribe_link`)
doesn't touch MailerLite, so it leaves a Signal subscription alone.

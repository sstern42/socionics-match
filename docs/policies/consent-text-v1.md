# Marketing-email consent wording, version v1

In use from 30 September 2026. Every `consent_events` row with
`consent_text_version = 'v1'` was recorded against the wording below. The
`source` column says which of the three capture points the member used.

Do not edit this file. Any change to this wording needs a new version string
(`v2`, …) in `set_marketing_preference()`, new source values where the capture
point's wording changes (for example `signup_v2`), and a new
`consent-text-v2.md` alongside this one. See `CLAUDE.md`.

## `signup_v1` — profile setup checkbox

Shown on `/profile/setup` (`src/pages/ProfileSetup.jsx`, text in
`SIGNUP_CONSENT_TEXT`, `src/lib/emailPreferences.js`). Unticked by default. An
unticked box is recorded as `marketing_opt_in = FALSE`.

> Send me occasional Socion updates by email. You can unsubscribe at any time.

## `in_app_prompt_v1` — one-time prompt for existing members

Shown once per browser session to signed-in members with
`marketing_opt_in IS NULL` (`src/components/MarketingConsentPrompt.jsx`).
Closing it without choosing records nothing.

> **Want occasional Socion updates by email?**
> News about new features and the community, a few times a year at most. You
> can change this any time in Settings.
>
> [Yes, send me updates] [No thanks]

## `settings` — preferences toggle

On `/profile/notifications` (`src/pages/ProfileNotifications.jsx`), in a
"Socion updates" section separate from the account notifications.

> **📬 Socion updates by email**
> Occasional news about new features and the community, a few times a year at
> most. You can also unsubscribe from the link in any of these emails.

## Opt-outs with no consent wording

`mailerlite_unsubscribe` and `email_unsubscribe_link` record an opt-out made
outside the app (MailerLite's unsubscribe, bounce or spam report, or the
signed unsubscribe link in Socion's Resend emails). Their `consent_events`
rows have `consent_text_version = NULL`.

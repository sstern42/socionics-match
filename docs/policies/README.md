# Policy and consent archive

Dated copies of what members were shown, so that what someone agreed to on a
given date can be reconstructed later. The live pages are
`src/pages/Privacy.jsx` and `src/pages/Terms.jsx`; these files are frozen
snapshots of them.

| File | In force from |
|---|---|
| [`privacy-2026-09-30.md`](privacy-2026-09-30.md) | Superseded the same day by revision 2, before release |
| [`privacy-2026-09-30-r2.md`](privacy-2026-09-30-r2.md) | 30 September 2026 |
| [`terms-2026-09-30.md`](terms-2026-09-30.md) | 30 September 2026 |
| [`consent-text-v1.md`](consent-text-v1.md) | 30 September 2026 |

Earlier versions (last updated 14 June 2026) were not archived; they are in
git history in `src/pages/Privacy.jsx` and `src/pages/Terms.jsx`.

When a policy changes: update the page, bump its "Last updated" date, and add
a new `privacy-YYYY-MM-DD.md` / `terms-YYYY-MM-DD.md` here (add `-r2`, `-r3`… for a
second change on the same date). Never edit an existing snapshot.
